# Security policy

## Reporting a vulnerability

Please don't open a public issue for security problems. Report them privately through GitHub:
[Report a vulnerability](https://github.com/maitrios/maitri-vicinae/security/advisories/new).

Include what you found, how to reproduce it, and which version or commit you tested. I'll acknowledge the report as soon as I can and keep you posted on the fix.

## Supported versions

Only the latest release gets security fixes.

## Scope

This covers the maitri Vicinae extension in this repository.
